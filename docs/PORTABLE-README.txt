本地密码库 0.5.3 · Windows x64

建议解压到 D:\Vault 后启动 D:\Vault\Vault.exe（也可选择其他目录）。需要系统已有 WebView2 Runtime，不需要 Node.js/Python/Rust。
数据库默认位于程序旁 data；首次启动为空库。

支持自由标签、账号密码、API 凭据、数据库信息、本地 MCP 引用填写。
MCP 权限按默认规则、标签、单条例外管理；收起只隐藏明细。旧分组自动迁移为标签，升级前自动生成加密数据库备份。
设置页复制 MCP 配置。AI 接口不返回凭据原文。填写到其他程序或文件后，其他工具可能读取目标内容。

删除进入垃圾桶，可恢复。永久清空只在桌面原生确认后执行，无 MCP 永久删除工具。
数据绑定原 Windows 用户与电脑；移动软件不等于可跨机恢复。
手动替换程序升级前，请退出全部桌面及 MCP 进程并备份完整 data。新格式不能用旧版打开。
清空不会擦除外部备份、磁盘快照或已填写的文件。

在线更新：设置 → 软件更新 → 下载更新 → 重启并更新。请先保存修改；多个 MCP 连接共享一份后台核心，更新时自动暂停并恢复，无需退出 AI 客户端。0.5.2 及更早版本首次迁移仍需重连一次 MCP。签名失败不替换程序，数据目录保持原样。0.4.x 首次需要手动更新。
