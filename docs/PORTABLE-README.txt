本地密码库 0.4.0 · Windows x64

解压后启动 Vault.exe。需要系统已有 WebView2 Runtime，不需要 Node.js/Python/Rust。
数据库默认位于程序旁 data；首次启动为空库。

支持自由标签、账号密码、API 凭据、数据库信息、本地 MCP 引用填写。
MCP 权限按默认规则、标签、单条例外管理；收起只隐藏明细。旧分组自动迁移为标签，升级前自动生成加密数据库备份。
设置页复制 MCP 配置。AI 接口不返回凭据原文。填写到其他程序或文件后，其他工具可能读取目标内容。

删除进入垃圾桶，可恢复。永久清空只在桌面原生确认后执行，无 MCP 永久删除工具。
数据绑定原 Windows 用户与电脑；移动软件不等于可跨机恢复。
升级前退出全部桌面及 MCP 进程，备份完整 data，再使用新版本。新格式不能用旧版打开。
清空不会擦除外部备份、磁盘快照或已填写的文件。
